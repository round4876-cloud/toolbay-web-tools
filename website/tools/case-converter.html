Where Different Casing Standards Apply

  • camelCase: Standard for JavaScript and TypeScript variable and function names.
  • PascalCase: Used for class names, React components, and C# types.
  • snake_case: Standard for Python variables, functions, and relational database column names.
  • kebab-case: Ideal for SEO-friendly URL slugs, REST API endpoints, and CSS class selectors.
  • CONSTANT_CASE: Standard for global configuration keys and environment variables.

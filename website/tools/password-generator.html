What Makes a Password Computationally Secure?

Security is a function of search space entropy measured in bits ($E = L \times \log_2(N)$), where $L$ is length and $N$ is pool size. A 20-character password drawn from a 94-character pool achieves ~131 bits of entropy, requiring over $10^{21}$ years for a modern supercomputing cluster to brute-force.
